# Mentor Ledger — Commitments & Session Log

One entry per mentor session, newest at the top of the Log. The mentor reads the last 3 entries at session start and audits any OPEN commitment before anything else — kept, broken, or renegotiated. No judgment theater, but no skipping it either.

## Entry template

```
### YYYY-MM-DD — [mode]
- State: [one line — where the founder is right now]
- Commitment: [one behavior or shipped artifact — never an intention]
- If-then: If [specific cue], then [specific action]
- Deadline: [date]
- Status: OPEN → later KEPT | BROKEN | RENEGOTIATED
```
